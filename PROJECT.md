# Project Profile

Use this file as the single source of project context.

## Research Project Title
- QCEW Employment & Establishment Dynamics

## Research Question
- How are employment, establishments, and average weekly wages changing across U.S. counties and industries over the year, using the most recent Quarterly Census of Employment and Wages (QCEW) release?

## Data in Scope

| Data Source | Type | Owner/Location | Time Coverage | Access Notes |
|---|---|---|---|---|
| Quarterly Census of Employment and Wages (QCEW) | Administrative establishment census | BLS, pulled via the QCEW open-data slice CSVs (`read_qcew_slice()` in `code/00_setup.R`) | 2018 Q1 – latest release (2025 Q4 as of 2026-06-06) | Public open-data files at `data.bls.gov/cew/data/api/`; private-sector (`own_code == 5`) focus. Replaced the removed `blscrapeR::qcew_api()` (audit CE-001). File layout: `Infrastructure/references/literature/data_dictionaries/`. |
| County population estimates | Survey/estimate | Census Bureau, via `tidycensus::get_estimates()` | Latest vintage | Requires Census API key. Used to threshold county ranking charts (≥100,000 population). |
| County geometry (TIGER/cartographic) | Geospatial | Census Bureau, via `tigris::counties()` | 2021 cartographic boundaries (parameterized) | Excludes AK/HI for map presentation. |
| County latitude/longitude reference | Reference table | `data/raw/us_county_latlng.txt` | Static | Used to place county points on animated maps. |

## Deliverables
- Animated over-the-year (OTY) maps of county employment and establishment change.
- National all-industry OTY employment and establishment growth time series.
- Industry-level establishment and employment slope charts.
- County ranking charts: top/bottom five for employment, establishment, and average-weekly-wage growth.
- Geographic spotlights (e.g., Washington, Maine; NAICS 54 professional services).

## Constraints
- The analysis pipeline runs in R (Windows or macOS) and requires live BLS and Census access plus geospatial packages (`sf`, `tigris`, `tidycensus`, `gganimate`). The QCEW pull reads the BLS open-data slice CSVs directly (no `blscrapeR` dependency). It was last run end-to-end on macOS (2026-06-06) generating the 2025 Q4 outputs.
- A Census API key must be configured for `tidycensus`.
- Outputs are regenerated by running `code/run_all.R` after setting the user path and target quarter.
