Code Error & Efficiency Report

Project: QCEW Employment & Establishment Dynamics · Target: code/ (refactored pipeline + archived legacy script) · Date: 2026-06-05 · Reviewer rules: .claude/rules/code-quality-rules.md

This report covers the legacy monolith (archive/QCEW_Analysis_2022_q3_date_3_08_2023.R) and the refactored pipeline (code/00_setup.R through code/06_figures_spotlight.R). Each finding lists a Status: Fixed (resolved in the refactor), Open (requires action before the pipeline will run/be correct), or Advisory.

Findings (CRITICAL → SUGGESTION)

CRITICAL CE-001 — Defunct data dependency: blscrapeR::qcew_api() removed · Status: Open (handoff blocker)

What: Every QCEW pull calls blscrapeR::qcew_api(). Verified via the package NEWS/changelog: qcew_api() (and the package's mapping functions) were removed from blscrapeR. The pipeline will not run until the data source is migrated.

Verified: blscrapeR NEWS (keberwein/blscrapeR), 2024 — "removed qcew_api" and "removed all mapping functions and data."

Recommended fix: Replace the qcew_api() call inside the existing year-quarter grid loop with a reader for the BLS QCEW open-data slice CSVs (https://www.bls.gov/cew/downloadable-data-files.htm), preserving columns area_fips, own_code, agglvl_code, industry_code, qtrly_estabs, month3_emplvl, oty_*. The loop, filters, and all downstream logic stay unchanged. Annotated inline in 01_build_dataset.R and 06_figures_spotlight.R.

HIGH CE-002 — Hard-coded factor levels in slope charts · Status: Fixed

What (legacy): Slope charts set factor(year_quarter_num, levels=c(2021.25,2021.5,...,2022.5), labels=c("2021-1",...)). Any quarter outside that literal set is silently dropped to NA, so the chart breaks for every release other than 2022 Q3.

Fix: 04_figures_timeseries.R and 06_figures_spotlight.R derive ordered period labels from the data (period_order_num = year*10 + qtr, period_chr = "YYYY-Q"), so the axis adapts to the target release automatically.

MEDIUM CE-003 — left_join() without explicit by= · Status: Fixed

What (legacy): Joins to population, industry_crosswalk, us_county_latlng, and counties relied on implicit common-column matching. This is fragile (a renamed/added shared column silently changes the join) and can alter row cardinality without warning.

Fix: All joins now pass explicit by= keys ("fips", "GEOID", "area_fips", "industry_code").

MEDIUM CE-004 — Hard-coded absolute paths and setwd() · Status: Fixed

What (legacy): path_project set to user-specific Dropbox paths, then setwd(). Non-portable and breaks on any new machine.

Fix: 00_setup.R / run_all.R use a project_directories list keyed by Sys.info()[["user"]] with repo-relative paths underneath; failure is loud if the user is unmapped.

LOW CE-005 — Ambiguous year + qtr/4 period encoding · Status: Fixed (slope charts) / Advisory (maps)

What: year_quarter = year + qtr/4 maps Q4 to the next integer year (2024 Q4 → 2025.0), which is why the legacy slope charts needed hand-built label vectors. Refactor uses explicit period_order_num/period_chr for slope-chart axes. The animated maps keep the numeric for the continuous transition timeline (cosmetic only).

SUGGESTION CE-006 — Unused packages loaded · Status: Fixed

What (legacy): ggforce, ggmap, ggrepel, and plm were loaded but never used. Fix: dropped from 00_setup.R with a note.

SUGGESTION CE-007 — Copy-pasted per-year pull loops · Status: Fixed

What (legacy): Ten near-identical blocks (five years × industry/national) each with a per-quarter loop. Fix: a single year-quarter pull_grid_df drives one loop for each slice; the target year is truncated at target_qtr_int.

INFO CE-008 — Orphan / incomplete data files · Status: Advisory

What: cb_2018_us_state_500k.shp ships without its sidecar files (.shx/.dbf/.prj), so it cannot be read as a shapefile. gadm36_USA_2_sp.rds is never referenced by the analysis. Both were relocated to data/raw/ for preservation; neither is used by the pipeline (geometry comes from tigris). Consider removing or completing them.
