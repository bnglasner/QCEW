Fabrication & correctness findings

CRITICAL AS-001 — Establishment map color encoded from the wrong variable (legacy bug, now fixed)

What was claimed: The legacy comment reads "Cap the visual % change … at 25%". What was found: the establishment color variable was seeded from the count change, not the percent change:

dynamic$oty_qtrly_estabs_pct_chg_edit <- dynamic$oty_qtrly_estabs_chg  (should be ...$oty_qtrly_estabs_pct_chg)

The diverging color scale (red↔green, midpoint 0, capped ±25) was therefore driven by raw establishment counts, not percentages — the map's color meaning did not match its legend or caption. Present in both the main establishment map and the NAICS 54 map. How verified: direct line read of archive/QCEW_Analysis_2022_q3_date_3_08_2023.R (lines 251, 693). Fix: corrected in 02_build_map_data.R and 06_figures_spotlight.R with inline markers; the employment map was always correct.

MEDIUM AS-002 — Verify get_estimates() arguments against current API

Claim: tidycensus::get_estimates(geography="county", product="characteristics", breakdown="SEX", breakdown_labels=TRUE). Found: verified against current tidycensus docs — for 2020+ the only supported product is "characteristics", breakdown accepts "SEX", and county geography is supported; PEP is served from a flat file (not the API) since 2020. The call is valid. Set vintage explicitly (see MR-002). Method: web verification of walker-data.com/tidycensus.

MEDIUM AS-003 — qcew_api() does not exist in current blscrapeR

Cross-referenced with code-error CE-001. The function is fabricated relative to the current package (it existed when the legacy script was written, but was removed). Flagged here as the most consequential "referenced entity no longer exists" issue. Method: blscrapeR NEWS/changelog.

LOW AS-004 — Edge-case fragility in ranking selection

na.omit() then head(5) assumes at least five non-missing counties remain after filtering to ≥100,000 population and the most-recent quarter. If a measure is sparse in a given release, the chart will silently show fewer than five bars. Low risk for large counties, but worth a guard (nrow check) or an explicit note.
